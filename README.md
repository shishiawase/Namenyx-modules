# Namenyx official modules

Signed distribution channel for official Namenyx modules.

Source URL: `https://raw.githubusercontent.com/shishiawase/Namenyx-modules/main/source.json`

The repository contains only public source metadata and compiled `.namenyxmod` release assets. Module source code and the Namenyx application source are maintained separately. Browser AI and other third-party modules are not published here.

Packages are verified by Namenyx using their declared size, SHA-256 digest and Ed25519 signature. Catalog updates are signed separately. Release assets are immutable; unchanged module versions continue using their existing package instead of being uploaded again.

Install modules from the Namenyx module library. Do not download or unpack DLL packages manually.
